# AKShare Docs

AKShare 是基于 Python 的财经数据接口库，目的是实现对股票、期货、期权、基金、外汇、债券、指数、加密货币等金融产品的基本面数据、实时和历史行情数据、衍生数据从数据采集、数据清洗到数据落地的一套工具，主要用于学术研究目的。

AKShare 的特点是获取的是相对权威的财经数据网站公布的原始数据，通过利用原始数据进行各数据源之间的交叉验证，进而再加工，从而得出科学的结论。

## 注意事项

这些文档都是从[官方文档](https://akshare.akfamily.xyz/index.html)中提取的，所以不一定是最新的，你可以运行下面的命令来更新文档。
```bash
uv run scripts/update_docs.py
```

请先尝试按照本地的文档能否跑通，如果不能跑通，再尝试更新文档。

每个文档可能会非常大，所以请不要尝试一次性读取所有文档，可以先查找某个关键字，再阅读相关的文档。
比如要查询`现货数据`里面的`生猪大数据`，可以先确认`生猪大数据`大概的行数后再读取相关的部分。
```bash
grep -n "生猪大数据" docs/data/spot/spot.md
```
